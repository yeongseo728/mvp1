## 1. 문제 (Problem)
1. 공인중개사나 집주인에게 **무엇을 물어봐야 하는지** 모른다.
2. 받은 답이 애매할 때 그것이 이후 **법적 분쟁이나 법적 보호에 어떤 영향**을 미칠지, 어떻게 대응해야 할지 판단하기 어렵다.
3. 등기부, 건축물대장, 확정일자·전입세대 정보, 미납 세금, 시세, 공인중개사 등록 정보, 보증보험 가입 가능 여부 등 **최소 7개의 정보가 여러 곳에 흩어져** 있고, 짧은 계약 과정 안에서 이를 비교해야 한다.

(근거: PRD 1번 문제, 3번 불편의 크기)

### 지금 쓰는 방법 (Existing Alternatives) — (제안 — 확인 필요)
- 블로그·커뮤니티 글을 찾아 읽기
- 부모님·선배 등 지인에게 묻기
- 공인중개사의 설명을 그대로 믿기

## 2. 고객 (Customer Segments)
- 서울(신촌 등)에서 부동산을 통해 **혼자 전월세 계약**을 진행하는 대학생
- 주거 탐색은 마쳤고, **계약 전 확인과 계약 판단**이 필요한 사람

### 처음 쓸 사람 (Early Adopters)
- 집은 골랐고 계약 직전인, 처음 혼자 계약하는 대학생 (근거: PRD 2번)
- 이후 넓힐 고객: 원룸·오피스텔을 계약하는 사회초년생 (근거: PRD 11번)

## 3. 고유 가치 (Unique Value Proposition)
> 확인할 질문을 체크리스트로 모아 주고, 들은 답을 고르면 법률 기준으로 영향과 다음 행동을 알려 줘요.

- 한 줄 요약: **"계약 전에 물어볼 것, 들은 답의 위험(🟢🟠🔴), 다음 행동을 한 번에"**

(근거: 앱 시작 화면 소개 세 줄, PRD 4번)

## 4. 해결책 (Solution)
1. **질문 체크리스트**: 15개 질문을 5개 묶음(상대방 확인, 권리관계 확인, 집 상태 확인, 계약 조건 확인, 돈이 오가는 순간)으로 제시
2. **답에 따른 판단**: 답을 고르면 🟢 비교적 안전 / 🟠 확인 필요 / 🔴 위험과 이유·주의사항·추천 행동·관련 법률을 보여 줌
3. **금액 계산**: 돌려받을 수 있는 보증금과 정당한 중개보수를 계산
4. (보조) 메모를 적은 경우 "메모 AI로 살펴보기"로 참고 의견 제공

(근거: PRD 4번, 6번)

## 5. 알리는 길 (Channels)
- 초기: 대학가 및 사회초년생 밀집 지역에서 판매 (근거: PRD 11번)
- 이후: 대학교·지자체와 제휴(B2G) (근거: PRD 11번)
- (제안 — 확인 필요) 대학 커뮤니티·학생회·학교 주거 안내 게시판에 링크 공유

## 6. 수익 (Revenue Streams)
- **계약 건당 1만 원 이하**의 이용료 (중개보수의 1~2% 수준, 구체적인 가격은 고객 검증 후 정함)
- 체크리스트는 **무료**로 제공해 사용자를 모으고, 항목별 **위험도 상세 분석과 구체적인 추천 행동은 유료**
- 이후 대학교·지자체와의 **B2G 제휴**로 추가 수익

(근거: PRD 11번)

## 7. 비용 (Cost Structure) — (제안 — 확인 필요)
- 사이트 운영비(Vercel)
- AI 사용료(Gemini — 지금은 무료 등급, 다른 사람에게 열기 전 유료 등급 검토)
- 법률·판단 기준을 공식 출처로 확인하고 법이 바뀔 때 고치는 시간
- 대학·지자체 제휴를 위한 영업·홍보 시간

## 8. 핵심 숫자 (Key Metrics) — (제안 — 확인 필요)
- 15개 질문을 끝까지 확인한 사람 수
- 🔴 위험 판단을 받은 뒤 추천 행동을 한 사람의 비율
- 무료 체크리스트에서 유료 상세 분석으로 넘어간 비율
- 제휴한 대학·지자체 수

## 9. 따라 하기 어려운 점 (Unfair Advantage) — (제안 — 확인 필요)
- 국가법령정보센터 등 **공식 출처로 확인한 서울 기준 판단 규칙** (`판단기준.md`)
- 사용자의 답을 **기기 밖으로 보내지 않는** 개인정보 보호 구조
- 대학생이 직접 겪는 문제에서 출발한 질문 구성과 쉬운 설명
