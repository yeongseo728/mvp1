# PRD v1.0

## 1. 문제
전세·월세 계약 전 확인해야 할 정보는 많지만 여러 곳에 흩어져 있어 정리하기 어렵다.
공인중개사나 집주인에게 무엇을 물어봐야 하는지, 받은 답변이 애매할 때 그것이 이후 법적 분쟁이나 법적 보호에 어떤 영향을 미칠지, 어떻게 대응해야 하는지도 판단하기 어렵다.
법을 모르는 사용자는 받은 답이 안전한지 스스로 판단하기 어렵다.

## 2. 고객
서울(신촌 등)에서 부동산을 통해 혼자 전월세 계약을 진행하는 대학생. 주거 탐색은 마쳤고, 계약 전 확인과 계약 판단이 필요한 사람.

## 3. 불편의 크기
전월세 계약자는 계약 전·계약 시·계약 후에 걸쳐 많은 핵심 확인사항을 살펴야 한다. 이 과정에서 등기부, 건축물대장, 확정일자·전입세대 정보, 미납 세금, 시세, 공인중개사 등록 정보, 보증보험 가입 가능 여부 등 최소 7개의 정보를 찾아야 한다.
특히 계약 상대방이 실제 소유자인지, 대리인이 적법한 계약 권한을 갖고 있는지, 주택에 근저당 등 선순위 권리가 있는지, 보증금이 시세와 비교해 안전한 수준인지처럼 여러 자료를 함께 비교해야 판단할 수 있는 항목이 있다. 계약 이후에도 계약일과 잔금일 사이 권리관계가 바뀔 수 있어, 등기부는 계약일과 잔금 지급 직전에 다시 확인해야 한다.
즉, 사용자는 짧은 계약 과정 안에서 여러 기관의 정보를 찾고, 서로 다른 서류와 답변을 비교하며, 계약 이후의 위험과 대응 방법까지 판단해야 한다.

## 4. 핵심 가치
- 계약 단계에서 확인해야 할 정보를 5개 묶음, 15개 질문의 체크리스트로 모아준다.
- 공인중개사나 집주인에게 물어봐야 할 질문과 그 이유를 제시한다.
- 사용자가 받은 답을 고르면, 앱이 대한민국 임대차 관련 법률과 서울 기준으로 🟢 비교적 안전 / 🟠 확인 필요 / 🔴 위험을 판단한다.
- 판단 이유와 법 조항, 주의사항, 다음 행동을 함께 보여준다.
- 예를 들어 집주인과 직접 계약하는 경우와 대리인과 계약하는 경우를 비교한다. 대리인이 위임장·인감증명서 없이 나오면 🔴로 판단하고, 법적 보호에서 어떤 차이가 있는지 알려준다.

## 5. 핵심 흐름 다섯 단계
1. 사용자가 서비스를 연다.
2. 사용자가 계약 전 확인 항목과 질문을 확인한다. 앱은 다음에 확인할 질문을 추천하고, 사용자는 원하는 질문을 순서와 상관없이 고를 수 있다.
3. 사용자가 공인중개사나 집주인에게 받은 답을 고르고, 필요한 금액을 입력한다.
4. 사용자가 앱의 판단 결과(🟢🟠🔴), 판단 이유, 영향, 다음 행동을 확인한다.
5. 사용자가 질문별 판단과 목록의 색 표시를 보고 계약 진행 여부를 판단한다.

## 7. 점검에서 걸린 것과 바꿀 것
- 점검에서 걸린 것: 다만 근저당권, 보증금이 계산하는 방식이 이상해서 적절한 보증금도 적절하지 않다고 나왔다
- 그래서 바꿀 것: 법률을 기준으로 우선 변제권 같은 걸 정리하고 보증금 계산을 명확하게 해줘

써 본 사람의 한마디: 질문이 많아 어렵지만 부동산 계약하는데 큰 도움이 될 것 같다 
그래서 바꿀 것: 꼭 필요한 질문인지 다시 한번 확인하여 질문 수를 줄이는 방향을 고려하겠다.

## 8. 이번 주 기능
- 질문화면(체크리스트): 확인한 질문 수와 진행 막대, 5개 묶음 15개 질문, 판단 색 표시, "다음 질문" 표시, "처음부터 다시 하기"
- 답변입력: 사실 고르기, 금액 입력(만 원 단위, 집 시세·보증금·월세는 한 번 입력하면 여러 질문이 함께 씀), 들은 말 메모(판단에는 쓰지 않음), 누가·어떻게 들었는지
- 영향행동(판단 결과): 🟢 비교적 안전 / 🟠 확인 필요 / 🔴 위험, 판단 이유와 법 조항, 주의사항, 추천 행동, 관련 법률, "다음 추천 질문 보기"·"체크리스트로 돌아가기"
- 판단 방식: 질문마다 정해진 법률 기준으로 판단하고(`판단기준.md`), 이유가 여러 개면 가장 나쁜 판단이 결과가 된다. 보증금은 법이 정한 순서(소액임차인 최우선변제 → 근저당·먼저 사는 세입자)대로 돌려받을 수 있는 금액을 계산해, 모두 받으면 🟢, 일부를 못 받으면 🔴로 판단한다. 지역마다 다른 숫자는 서울 기준이다.
- 데이터와 개인정보: 답, 금액, 메모는 사용자 기기의 브라우저 안에만 저장하고 서버나 외부로 보내지 않는다.
- 법적 안내 문구: 참고용 안내이며 법률 자문이 아니고, 이 안내를 바탕으로 한 결정과 그 결과에 대해 집콕체크는 책임지지 않는다.

## 9. 다음 기능
- 최종 요약: 15개 질문의 판단을 모아 계약 진행 여부 판단을 돕는 요약
- 압류·가압류 확인: 등기부의 압류·가압류 등 선순위 권리를 묻는 질문
- 잔금 직전 재확인: 잔금 지급 직전에 등기부를 다시 확인하는 단계
- 판단 기준 공식 출처 재확인: `판단기준.md`의 숫자를 공식 출처로 다시 확인
- AI 보충 설명: 메모를 AI가 읽고 놓친 점을 덧붙임. AI는 판단 색을 바꾸지 않음. 메모를 외부로 보내야 하므로 개인정보 원칙과 충돌해 만들기 전에 다시 정함

## 10. 안 할 것
- 로그인 (이유: 거부감을 불러일으킬 수 있음)
- 결제 (이유:앱의 확실성이 보장되지 않음 )
- 알림 (이유: 크게 필요하지 않다고 판단함)
- 실제 부동산 매물 검색·추천 기능 (이유:이미 다른 앱에서 많이 사용되고 있는 기능임, 차별화x  )
