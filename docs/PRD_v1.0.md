# PRD v1.0

## 1. 문제
전세·월세 계약 전 확인해야 할 정보는 많지만 여러 곳에 흩어져 있어 정리하기 어렵다.
공인중개사나 집주인에게 무엇을 물어봐야 하는지, 받은 답변이 애매할 때 그것이 이후 법적 분쟁이나 법적 보호에 어떤 영향을 미칠지, 어떻게 대응해야 하는지도 판단하기 어렵다.

## 2. 고객
서울(신촌 등)에서 부동산을 통해 혼자 전월세 계약을 진행하는 대학생. 주거 탐색은 마쳤고, 계약 전 확인과 계약 판단이 필요한 사람.

## 3. 불편의 크기
월세 계약자는 계약 전·계약 시·계약 후에 걸쳐 많은 핵심 확인사항을 살펴야 한다. 이 과정에서 등기부, 건축물대장, 확정일자·전입세대 정보, 미납 세금, 시세, 공인중개사 등록 정보, 보증보험 가입 가능 여부 등 최소 7개의 정보를 찾아야 한다.
특히 계약 상대방이 실제 소유자인지, 대리인이 적법한 계약 권한을 갖고 있는지, 주택에 근저당·압류 등 선순위 권리가 있는지, 보증금이 시세와 비교해 안전한 수준인지처럼 여러 자료를 함께 비교해야 판단할 수 있는 항목이 있다. 계약 이후에도 계약일과 잔금일 사이 권리관계가 바뀔 수 있어, 등기부는 계약일과 잔금 지급 직전에 다시 확인해야 한다.
즉, 사용자는 짧은 계약 과정 안에서 여러 기관의 정보를 찾고, 서로 다른 서류와 답변을 비교하며, 계약 이후의 위험과 대응 방법까지 판단해야 한다.

## 4. 핵심 가치
부동산 계약 단계에서 확인해야 할 정보를 단계적으로 제공하고 체크리스트로 모아준다.
사용자에게 공인중개사나 집주인에게 물어봐야 할 질문을 제시한다. 사용자가 받은 답변을 입력하면, 해당 답변이 이후에 미칠 수 있는 영향과 다음 행동을 안내한다. 예를 들어 집주인과 직접 계약하는 경우와 계약자가 아닌 대리인과 계약하는 경우를 비교하여, 이후 법적 분쟁 발생 시 법적 보호 측면에서 어떤 차이가 있을 수 있는지 알려주고 사용자가 행동을 선택할 수 있게 한다.

## 5. 핵심 흐름 다섯 단계
1. 사용자가 서비스를 연다.
2. 사용자가 계약 전 확인 항목과 질문을 확인한다.
3. 사용자가 공인중개사나 집주인에게 받은 답변을 입력한다.
4. 사용자가 답변이 이후에 미칠 수 있는 영향과 다음 행동을 확인한다.
5. 사용자가 계약 진행 여부를 판단한다.

## 6. 지금 있는 것
- 내 페이지 주소: https://mvp1-snowy.vercel.app/
- 앱 소개 세 줄(문제·고객·핵심 가치)
- "시작하기" 버튼, 저장된 답이 있으면 "이어서 하기 / 새로 시작하기" 버튼
- 이어서 하기는 저장된 기록을 불러와 이어서 확인하고, 새로 시작하기는 저장된 답을 지우고 처음부터 다시 시작
- 확인한 질문 수 표시 
- 질문 체크리스트: 질문 15개를 내용에 따라 5개 묶음으로 나눔 (상대방 확인 4개, 권리관계 확인 4개, 집 상태 확인 1개, 계약 조건 확인 3개, 돈이 오가는 순간 3개)
- 질문마다 객관식 답변 선택
- 주관식 답변 메모
- 누가 답했는지(공인중개사·집주인) 선택
- 어떻게 들었는지(구두·문자·메신저·서류) 선택
- 답변을 사용자 기기 안에만 저장 (서버나 외부로 보내지 않음)
- 판단 방식: 공식 출처로 정리한 판단 기준에 따라 답변마다 🟢 비교적 안전 / 🟠 확인 필요 / 🔴 위험으로 판단하고, 이유가 여러 개면 가장 나쁜 판단이 결과가 됨. 지역마다 다른 숫자는 서울 기준
- 판단 결과 화면에 판단 이유, 주의사항, 추천 행동 표시
- 관련 법률 제시
- 돌려받을 수 있는 보증금 계산 기능 (법이 정한 순서: 최우선변제 → 근저당·먼저 사는 세입자)
- 정당한 중개보수 계산 기능
- 답변 연결: 앞 질문의 답변을 반영해 지금 질문의 주의 정도를 판단하고, 앞 답변 때문에 필요 없어진 질문은 체크리스트에서 회색 "해당 없음"으로 표시
- "처음부터 다시 하기" 버튼
- 법적 안내 문구: 참고용 안내이며 법률 자문이 아니고, 이 안내를 바탕으로 한 결정과 그 결과에 대해 집콕체크는 책임지지 않는다고 명시
- "다음 추천 질문 보기" 버튼
- "답변 저장하고 체크리스트로 돌아가기" 버튼
- 메모 AI로 살펴보기: 메모를 적은 경우, 사용자가 보내기를 누르면 AI가 관련 법률 안에서 참고 의견(위험 높음/더 확인 필요/위험 낮음/판단 어려움)을 보여 줌. 판단 색은 바꾸지 않음.

## 7. 점검에서 걸린 것과 바꿀 것
- 점검에서 된 것: 모든 버튼이 다 잘 눌렸고, 선택에 따른 위험도와 그 근거도 표시해 줬다.
- 점검에서 걸린 것
  - 숫자로 판단하는 기준(보증금 우선변제금, 부동산 중개보수)이 잘못 계산됐다.
  - 관련 법률의 출처가 명확하지 않았다.
  - 서로 관련 있는 질문끼리 답변이 연결되지 않았다.
  - 답변이 기기에 저장되는 방식이라, 같은 기기에서 링크로 다시 들어가면 이전 답변이 그대로 남아 있었다.
- 그래서 바꿀 것
  1. 명확한 출처를 반영한 판단 기준 제시
  2. 질문들끼리 유기적 연결
  3. 새로 시작하기 / 이어서 하기 선택 버튼 넣기
- 써 본 사람의 한마디: 질문이 많아 어렵지만 부동산 계약하는 데 큰 도움이 될 것 같다.
  - 그래서 바꿀 것: 꼭 필요한 질문인지 다시 한번 확인하여 질문 수를 줄이는 방향을 고려하겠다.

## 8. 이번 주 기능
1. 보증금 변제액·정당한 중개보수 예측 기능
   - 화면: 답변입력 화면 → 판단 결과(위험성 예측 및 주의) 화면
   - 무엇을 하는가: 사용자가 보증금, 월세, 집 시세, 근저당 금액, 계약한 건물의 종류를 앱에 입력한다.
   - 어떻게 되는가: 관련 법령과 계산 과정을 보여 주면서 돌려받을 수 있는 보증금(변제금)이 얼마인지 알려 주고, 중개보수가 정당한지 판단한다.

## 10. 안 할 것
- 알림 (이유: 크게 필요하지 않다고 판단함)
- 실제 부동산 매물 검색·추천 기능 (이유: 이미 다른 앱에서 많이 사용되고 있는 기능임, 차별화 없음)

## 11. 비즈니스 모델
대학생 및 사회초년생이 원룸·오피스텔 계약 시 필수 확인 사항인 리스크 분석 및 대응 가이드를 확인하기 위해 건당 1만 원 이하의 이용료를 지불한다.

* 체크리스트를 무료로 제공하여 사용자를 모으고 계약 위험을 스스로 깨닫게 한다.

* 체크리스트 답변을 바탕으로 한 항목별 위험도 상세 분석 그리고 구체적인 추천 행동 제시 부분을 유료화한다.

* 중개보수의 1~2%인 1만 원 이하의 가격으로 책정한다. (구체적인 가격은 고객 검증 후 책정 예정)

* 초기에는 대학가 및 사회초년생 밀집 지역의 대학생·사회초년생을 대상으로 판매한 후, 대학교 및 지자체와의 B2G 제휴 사업으로 안정적인 추가 수익을 도모할 예정이다.
